# Competitive Landscape (actualizado mayo 2026)

## Competidores directos — AI para hotelería

| Plataforma | Canales | Fortaleza | Debilidad | Precio estimado |
|------------|---------|-----------|-----------|-----------------|
| **Conduit** | Voz + WhatsApp + SMS + email + OTA | Líder actual, todo unificado | Caro, enfocado en hoteles grandes | Alto |
| **HiJiffy** | Web chat + WhatsApp + Facebook + Instagram | Multilenguaje, fácil de instalar | Solo chat, sin automatización de backend | Medio |
| **Asksuite** | WhatsApp + Facebook + Instagram + web | Inbox centralizado, booking-focused | Sin gestión operativa del hotel | Medio |
| **Akia** | SMS + email + WhatsApp | Automatiza guest journey completo | Templates rígidos, poca personalización | Medio |
| **Myma AI** | Web + WhatsApp | Especializado en hospitalidad boutique | Menos conocido, menos integraciones | Bajo-medio |

## Nuestra posición (Timeless)

**Segmento target:** hoteles chicos (4–30 habitaciones) que no pueden pagar Conduit o HiJiffy.
**Canal actual:** web chat (Emma via @n8n/chat SDK)
**Canal siguiente:** WhatsApp Business (pendiente número de Ana)

## Features que los competidores tienen y nosotros no (aún)

1. **Guest journey automation** — mensajes automáticos pre/during/post estadía → en roadmap
2. **Unified inbox** — un lugar para ver todos los mensajes de todos los canales → largo plazo
3. **Review request** — pedir Google Review automáticamente post-checkout → en roadmap
4. **Integración PMS** — leer disponibilidad en tiempo real desde Opera/Mews/Cloudbeds → largo plazo
5. **Voz** — atender llamadas con IA → no prioritario ahora

## Lo que hacemos mejor que ellos

- Precio accesible para hoteles chicos
- Setup personalizado (nombre del bot, colores, personalidad)
- Knowledge base customizada con RAG (no solo FAQ predefinidas)
- Dashboard y panel propios (Netlify, sin costo extra)
- Flexibilidad total via n8n (podemos automatizar cualquier cosa)
